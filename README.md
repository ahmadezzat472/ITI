# ITI (Information Technology Institute)

This repository contains course materials, projects, and assignments from the Information Technology Institute (ITI) training program.

## 📚 Repository Structure

### Backend
Backend development materials and projects:
- **MongoDB** - NoSQL database materials and examples
- **Node.JS** - Server-side JavaScript development

### Client-Side
Front-end development materials:
- **Frameworks** - Modern JavaScript frameworks and libraries
- **Fundamentals** - Core front-end development concepts

### Data-Structure
Data structures and algorithms course materials organized by day:
- **Day 1** - Sorting and Searching algorithms
- **Day 2** - LinkedList implementations
- **Day 3** - Stack and Queue data structures
- **Day 4** - Trees and tree-based algorithms

### Database
Database design and SQL materials:
- **Day 1** - ERD (Entity Relationship Diagrams)
- **Day 2** - Mapping and SQL Introduction
- **Day 3** - Normalization and Join operations
- **Days 4-5** - Advanced database concepts
- **Others** - Additional database resources

### OPP-C++
Object-Oriented Programming with C++ course:
- **Day 1** - Introduction to C++
- **Day 2** - Magic Box exercise
- **Day 3** - Fundamentals
- **Day 4** - Pointers
- **Day 5** - Dynamic Allocation
- **Day 6** - Classes and Namespaces
- **Day 7** - Constructors and Stack
- **Day 8** - Copy Constructors
- **Day 9** - Inheritance and Association
- **Day 10** - Advanced Inheritance
- **Demos** - Code demonstrations and examples

### Network
Network programming and concepts:
- Network fundamentals organized by day (Days 1-3)

### OS
Operating Systems course materials:
- Lecture PDFs covering various OS concepts
- Process management
- Threads
- And more

### SWE (Software Engineering)
Software engineering principles and documentation:
- Software Development and Professional Practice resources
- Software Requirements Specification (SRS) templates
- Test case examples and documentation
- Comprehensive lecture materials
